# 同行评审规程

| 属性 | 内容 |
|------|------|
| 文档编号 | OPA-QA-PR-001 |
| 版本 | 1.0 |
| 映射 | CMMI: VER（同行评审）, PPQA；ISO 12207: 6.4.6 Verification |

## 1. 目的

通过同行检查尽早发现缺陷与过程遗漏，提升工作产品质量。

## 2. 适用对象

需求、设计、关键代码、测试计划/用例、发布说明（按项目裁剪）。

## 3. 评审类型

| 类型 | 适用 | 说明 |
|------|------|------|
| 走查 | 文档/设计 | 作者讲解，评审人提问 |
| 检查单评审 | 各工作产品 | 按对应检查单逐项 |
| 拉取请求评审 | 代码 | 工具化；合并前完成 |

## 4. 流程

1. **计划**：确定对象、评审人、时间（可在迭代计划中）。
2. **准备**：材料冻结一小版本；分发检查单。
3. **执行**：记录问题（严重/一般/建议）；不现场争论过久。
4. **返工与验证**：作者修复；评审人确认关闭。
5. **度量**：记录缺陷数、工时（可选，供 MA）。

## 5. 评审记录最小字段

| 字段 | 内容 |
|------|------|
| 对象 / 版本 | |
| 类型 | |
| 评审人 | |
| 日期 | |
| 结论 | 通过 / 修改后通过 / 不通过 |
| 问题列表 | ID、描述、级别、状态 |

## 6. 规则

- 作者不担任唯一评审人
- 阻断级问题未关闭不得基线/合并/发布
- 检查单见同目录各文件
