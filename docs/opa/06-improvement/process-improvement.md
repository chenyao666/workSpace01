## 1. 目的

基于项目经验、度量、PPQA 与业务需要，持续改进组织过程资产并推广。

## 2. 改进循环

```
识别问题/机会 → 分析根因 → 提出改进 → 试点 → 更新 OPA → 推广培训 → 评价效果
```

## 3. 改进来源

- 项目结项回顾与行动项
- PPQA NCR 趋势
- 度量异常（逃逸缺陷、里程碑延误等）
- 外部标准/技术变化（自愿对齐，非证书宣称）
- 员工建议

## 5. 活动要点

1. **定期回顾**：建议每季度一次过程回顾会（可与全员会合并，30–60 分钟）。
2. **优先级**：影响交付质量/重复浪费者优先。
3. **试点**：重要过程变更先在 1 个项目试用，收集反馈。
4. **纳入 OPA**：更新对应规程/模板版本；通知全员（链 OT）。
5. **效果评价**：对比相关度量或定性反馈；无效则回退。
