# 组织培训简要规程（OT）

| 属性 | 内容 |
|------|------|
| 文档编号 | OPA-OT-001 |
| 版本 | 1.0 |
| 映射 | CMMI: OT；ISO 12207: 6.2.4 |

## 1. 目的

确保承担关键角色的人员理解组织过程与必要技能，并能按 OPA 执行。

## 2. 培训类别

| 类别 | 内容示例 | 对象 |
|------|----------|------|
| 过程培训 | 本 OPA 概览、裁剪、CM、评审、发布门禁 | 全员 |
| 角色培训 | PM：计划/PMC/风险；QA：PPQA；开发：评审与追溯 | 对应角色 |
| 工程技能 | 语言框架、安全编码、测试工具 | 按项目 |
| 新员工导入 | 政策、架构、模板位置、必读清单 | 新人 |

## 3. 主要活动

1. **识别需求**：立项/计划时填写培训需求；年度盘点角色能力缺口。
2. **计划**：主题、对象、方式、日期、材料。
3. **实施**：讲授/实操/自学；保留签到。
4. **记录**：使用 [培训记录模板](../04-templates/training-record.md)。
5. **评价**：抽查是否在项目中应用；不足则补训。

## 4. 必读清单（新成员 / 新项目）

1. [组织政策](../00-governance/01-org-policy.md)
2. [过程架构](../00-governance/02-process-architecture.md)
3. [裁剪指南](../00-governance/03-tailoring-guide.md)
4. 与角色相关的生命周期/管理规程
5. 常用模板与检查单位置（`04-templates/`、`03-quality/`）

## 5. 角色能力最低期望（小型团队）

| 角色 | 最低期望 |
|------|----------|
| PM | 能写简版计划、维护风险与状态、执行裁剪 |
| 开发 | 能关联需求 ID、完成评审、遵守 CM |
| 测试 | 能写用例、记缺陷、做回归 |
| QA 兼职 | 能用 PPQA 检查单抽查并开 NCR |

## 6. 工作产品

- 培训计划（可附组织年度表或项目计划第 12 节）
- 培训记录与材料索引
