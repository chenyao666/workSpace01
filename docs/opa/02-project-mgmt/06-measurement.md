## 1. 目的

采集少量可落地指标，支持 PMC 监控与组织过程改进（OPF），避免度量形式主义。

## 2. 原则

- 指标少而稳（见 [度量与基线定义](../05-metrics/metrics-and-baselines.md)）
- 能从现有工具自动取数优先（Git、看板、缺陷库）
- 每个指标有用途与责任人

## 3. 主要活动

1. 在项目计划中确认本项目度量集（可裁剪，不可低于强制最小集）。
2. 按迭代/周采集并填入度量表。
3. 在状态报告中解读偏差。
4. 结项汇总提交组织度量库（可用共享表格）。
