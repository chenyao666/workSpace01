# 项目监控与控制规程

| 属性 | 内容 |
|------|------|
| 文档编号 | OPA-PM-PMC-001 |
| 版本 | 1.0 |
| 映射 | CMMI: PMC；ISO 12207: 6.3.2 Project assessment and control |

## 1. 目的

对照计划跟踪进展、问题与承诺，必要时采取纠正措施并更新基线。

## 2. 监控节奏（建议）

| 活动 | 频率 | 输出 |
|------|------|------|
| 站会/进度同步 | 日或隔日 | 障碍列表 |
| 迭代评审/演示 | 每迭代 | 验收结论 |
| 状态报告 | 周 | 进度、风险、度量摘要 |
| 里程碑评审 | 按门禁 | 继续/调整/终止决策 |

## 3. 主要活动

1. 跟踪任务完成、里程碑、工作量与范围变化。
2. 审查风险、问题、变更积压。
3. 对比度量（进度偏差、逃逸缺陷等）。
4. 识别偏离 → 纠正措施（加人、砍范围、改期、技术调整）。
5. 重大偏离升级决策；更新计划基线（CR）。
6. 阶段/项目结束：总结与改进项录入 OPF。
