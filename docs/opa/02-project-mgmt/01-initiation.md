## 1. 目的

确认业务价值、可行性与约束，批准项目启动并指定责任人。

## 2. 入口 / 出口

**入口**：业务诉求或维护立项申请。  
**出口**：立项批准（或拒绝）；指定 PM/TL；初步范围与成功标准；进入计划过程。

## 3. 主要活动

1. 填写立项简表（见下）。
2. 粗估规模、工期、成本与主要风险。
3. 识别干系人与依赖（环境、数据、外部系统）。
4. 决策：批准 / 有条件批准 / 驳回；记录理由。
5. 建立项目空间（代码库、文档夹、看板）。
