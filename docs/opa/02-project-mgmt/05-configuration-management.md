# 配置管理规程

| 属性 | 内容 |
|------|------|
| 文档编号 | OPA-PM-CM-001 |
| 版本 | 1.0 |
| 映射 | CMMI: CM；ISO 12207: 6.3.5 Configuration management |

## 1. 目的

识别配置项（CI）、控制变更、记录状态、支持审计与可复现发布。

## 2. 配置项类别（最小集）

| 类别 | 示例 | 仓库/位置 |
|------|------|-----------|
| 代码 | 源码、构建脚本、IaC | Git |
| 文档 | SRS、设计、计划、发布说明 | Git/文档库 |
| 构建产物 | 安装包、镜像 | 制品库 |
| 环境配置 | 配置模板（无密钥） | Git |
| 工具基线 | 依赖锁文件 | Git |

## 3. 主要活动

1. **识别 CI** 与命名/版本规则（如 SemVer、`YYYY.MM.DD`+构建号）。
2. **控制**：分支策略（如 main + feature）；合并审查；基线标签。
3. **变更**：基线后变更关联 CR；紧急变更事后补单。
4. **状态记账**：版本、基线内容清单、已知差异。
5. **审计**：发布前核对标签内容与发布说明一致（可与 PPQA 合并）。

## 4. 基线类型

| 基线 | 典型内容 |
|------|----------|
| 需求基线 | SRS + RTM |
| 设计基线 | 设计说明 |
| 产品基线 | 可发布构建 + 发布说明 |
| 计划基线 | 项目计划 |

## 5. 分支与标签约定（默认）

- `main`：可发布历史
- `feature/*`、`fix/*`：开发
- 标签：`vX.Y.Z` 对应发布

## 6. 工作产品

- CI 清单、基线记录、变更与审计记录
