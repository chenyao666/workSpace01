# 决策分析与解决（DAR）规程

| 属性 | 内容 |
|------|------|

| 版本 | 1.0 |
| 映射 | CMMI: DAR；ISO 12207: 6.3.3 Decision management |

## 1. 目的

对影响较大的备选方案进行结构化评价，留下可审计的决策记录。

## 2. 何时强制使用 DAR

- 技术栈/架构重大选型
- 自制 vs 外购/开源引入（有许可或安全影响）
- 重大范围取舍或供应商选择
- 高风险缓解方案在多个昂贵选项间抉择

日常小决策不强制；可在设计说明中简述理由。

## 3. 步骤

1. 明确决策问题与成功准则。
2. 列出备选方案（≥2）。
3. 定义评价准则与权重（成本、风险、工期、可维护性、安全等）。
4. 评分并记录假设与证据。
5. 选定方案与残余风险；沟通干系人。
6. 归档决策记录；相关风险入风险表。
