# 过程与产品质量保证（PPQA）规程

| 属性 | 内容 |

| 版本 | 1.0 |
| 映射 | CMMI: PPQA；ISO 12207: 6.3.7 Quality assurance |

## 1. 目的

客观评价过程遵循情况与关键工作产品质量，推动不符合项关闭，并向管理层与 OPF 提供可见性。

## 2. 独立性

小型团队允许兼职 QA，但**检查人不宜只检查自己刚执行的活动**；可采用项目间交叉或轮值。

## 3. 主要活动

1. **制定 PPQA 计划**：检查对象、抽样、时间点（可附于项目计划）。
2. **过程检查**：对照规程/裁剪记录，抽查是否执行（如是否有评审、变更是否有 CR）。
3. **产品检查**：抽查工作产品完整性与检查单覆盖（需求、设计、测试、发布记录等）。
4. **记录不符合项（NCR）**：描述、严重级别、责任人、到期日。
5. **跟踪关闭**；系统性议题升级到过程改进。
6. **沟通**：向 PM 与组织过程负责人报告趋势。
