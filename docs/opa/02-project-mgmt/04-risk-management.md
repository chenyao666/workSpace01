# 风险管理规程

| 属性 | 内容 |
|------|------|
| 文档编号 | OPA-PM-RSK-001 |
| 版本 | 1.0 |
| 映射 | CMMI: RSKM；ISO 12207: 6.3.4 Risk management |

## 1. 目的

系统识别、分析、缓解与监控项目风险，降低目标失败概率与影响。

## 2. 主要活动

1. **识别**：技术、进度、资源、依赖、安全/合规、供应方。
2. **分析**：可能性 × 影响 → 风险等级；确定优先级。
3. **应对**：规避 / 转移 / 缓解 / 接受；指定责任人与触发条件。
4. **监控**：状态会回顾；新风险随时登记。
5. **升级**：高等级风险无法缓解时提交管理层。

## 4. 与其他过程接口

- 计划阶段输出初版风险；DAR 可处理高不确定性技术选项
- 问题（已发生）进问题报告；风险（未发生）保留在风险表

## 5. 裁剪

- B/C 类：维护 Top5 风险即可；仍须对高风险有应对一句话。
