# 项目计划过程规程

| 属性 | 内容 |
|------|------|
| 文档编号 | OPA-PM-PP-001 |
| 版本 | 1.0 |
| 映射 | CMMI: PP, IPM；ISO 12207: 6.3.1 Project planning |

## 1. 目的

建立可执行、可监控的项目计划，包含范围、进度、资源、质量、风险、CM 与度量安排。

## 2. 入口 / 出口

**入口**：立项批准。  
**出口**：项目计划基线；裁剪记录；团队承诺（评审通过）。

## 3. 主要活动

1. 明确范围与交付物清单。
2. 工作分解（WBS/看板史诗）、估算（专家/类比/故事点）。
3. 进度与里程碑、依赖与关键路径。
4. 资源与角色、培训需求（链 OT）。
5. 质量计划：评审点、测试策略摘要、PPQA 抽查点。
6. 风险初版、CM 策略、度量采集计划。
7. 使用 [项目计划模板](../04-templates/project-plan.md) 成文并评审。
8. 基线化计划；变更走 CR。

## 4. 计划最小内容

- 目标与范围、里程碑、角色、生命周期/裁剪、风险摘要、沟通节奏、发布策略

## 5. 工作产品

- 项目计划（含裁剪附录）
- 进度表/看板、风险列表初版
