# 验证与确认（V&V）过程规程

| 属性 | 内容 |
|------|------|
| 文档编号 | OPA-LC-VV-001 |
| 版本 | 1.0 |
| 映射 | CMMI: VER, VAL；ISO 12207: 6.4.6 Verification, 6.4.8 Transition（部分）, 6.4.9 Validation |

## 1. 目的

- **验证（Verification）**：证明产品正确实现了规格（是否做对）。
- **确认（Validation）**：证明产品满足预期用途与干系人需要（是否做了该做的）。

## 2. 入口 / 出口

**入口**：可测需求/设计；测试环境可用；构建可安装。  
**出口**：测试报告；验收/确认结论；遗留缺陷分级与处置计划。

## 3. 验证活动

1. 制定 [测试计划](../04-templates/test-plan.md)（范围、策略、环境、进入退出准则）。
2. 设计 [测试用例](../04-templates/test-case.md)，覆盖功能与约定的非功能。
3. 执行：单元、集成、系统、回归；记录结果与缺陷。
4. 同行评审测试资产（可选但推荐）；用 [测试检查单](../03-quality/05-checklist-test.md)。
5. 验证追溯：需求 → 用例 → 结果。

## 4. 确认活动

1. 与干系人约定验收标准（可写入 SRS）。
2. 演示/UAT/试运行；收集书面或邮件确认。
3. 确认环境尽量接近生产或说明差异。
4. 未通过项：变更范围、延期或带条件发布（须批准）。

## 5. 工作产品

- 测试计划、用例、执行记录、缺陷报告
- 验证报告摘要；确认/验收记录

## 6. 裁剪提示

- B 类：测试计划可并入迭代说明；用例用检查表。
- C 类：复现步骤 + 回归范围 + 结果截图/日志即可。
